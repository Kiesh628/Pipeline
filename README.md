# Havent given this thing a name yet but working on it

> Automated building energy modelling tool with AI capabilities.

## Features:
- BIM to BEM converter with automated repair and autosizing capabilities
- Automated weather file retrieval
- Object Oriented, highly customizable data models
- Native ASHRAE/Honeybee templates
- Base linear classic matrix-based control system that can transition to a ML based control system (Residual Reinforcement Learning)
- Full psychrometric control 
- MCP1 to support agentic diagnosis, repair and modelling workflows to allow Engineering functionalities
- MCP2 to support natural language interaction for dynamic dashboards, supporting thermostat controls
- Native (virtual) BACnet support for control systems
- Energyplus driven simulations
- Server-Client Architecture via HTTP REST API
